QUICK INSTALL (Windows)
============================================================

1. Install FFmpeg:
   - Download: https://www.gyan.dev/ffmpeg/builds/
   - Extract to C:\ffmpeg
   - Add C:\ffmpeg\bin to PATH
   - Restart Command Prompt

2. Install Python packages:
   pip install -r requirements.txt

3. Test:
   python tiktok_to_youtube.py

Done! 🎉

============================================================
QUICK INSTALL (Oracle Cloud)
============================================================

1. SSH into VM:
   ssh -i oracle-ssh-key.key ubuntu@YOUR_IP

2. Install FFmpeg:
   sudo apt update
   sudo apt install ffmpeg -y

3. Upload new files:
   (From Windows PowerShell)
   scp -i oracle-ssh-key.key tiktok_to_youtube.py ubuntu@YOUR_IP:~/tiktok-youtube/
   scp -i oracle-ssh-key.key config.json ubuntu@YOUR_IP:~/tiktok-youtube/
   scp -i oracle-ssh-key.key video_processor.py ubuntu@YOUR_IP:~/tiktok-youtube/
   scp -i oracle-ssh-key.key requirements.txt ubuntu@YOUR_IP:~/tiktok-youtube/

4. Install packages:
   cd ~/tiktok-youtube
   pip3 install -r requirements.txt

5. Restart service:
   sudo systemctl restart tiktok-youtube
   sudo journalctl -u tiktok-youtube -f

Done! 🎉
