============================================================
TROUBLESHOOTING:
============================================================

"No videos found"
→ TikTok might be blocking automated requests
→ Use video_urls.txt to add URLs manually
→ Script will keep trying every 5 minutes

"Person detected, skipping"
→ Working as intended! Video had people in it
→ To disable: Set "skip_female_videos": false in config.json

"Watermark not showing"
→ Install FFmpeg (see INSTALL_FFMPEG_WINDOWS.txt)
→ Or disable: Set "add_watermark": false

"Video not splitting"
→ Install FFmpeg
→ Or disable: Set "split_long_videos": false

Encoding errors:
→ Run with: chcp 65001 ; python tiktok_to_youtube.py
→ Or use run_forever.bat
