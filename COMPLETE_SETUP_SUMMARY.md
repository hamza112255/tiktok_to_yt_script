## Troubleshooting

### Local Issues
- **"client_secret_X.json not found"** → Check files are in project root
- **"token_X.json not found"** → Run `python authenticate_all_projects.py`
- **Authentication fails** → Verify OAuth credentials are "Desktop app" type

### Railway Issues
- **"YouTube upload disabled"** → Check all 6 environment variables are added
- **"YouTube token invalid"** → Re-authenticate locally and re-encode
- **Wrong project used** → Check variable names match exactly (case-sensitive)
