## How The Rotation Works

### Automatic Selection
The script automatically selects which project to use based on the **day of the month**:

```
Day 1, 4, 7, 10, 13, 16, 19, 22, 25, 28, 31 → Project 1
Day 2, 5, 8, 11, 14, 17, 20, 23, 26, 29     → Project 2
Day 3, 6, 9, 12, 15, 18, 21, 24, 27, 30     → Project 3
```

### Benefits
- **3x More Quota**: 30,000 units/day instead of 10,000
- **~150 Uploads/Day**: Instead of ~50 uploads/day
- **Automatic**: No manual switching needed
- **Same Channel**: All uploads go to your YouTube channel
- **Seamless**: Works exactly like before

### No Code Changes Needed
- The rotation happens automatically
- You don't need to modify any code
- Just run your script normally

## Troubleshooting

### "client_secret_X.json not found"
- Verify files are in the project root directory
- Check file names are exactly: `client_secret_1.json`, etc.
- No extra spaces or characters

### "token_X.json not found"
- Run `python authenticate_all_projects.py`
- Make sure you complete the browser authentication
- Check for error messages during authentication

### Authentication fails
- Verify you created "Desktop app" credentials (not Web app)
- Check OAuth consent screen is configured
- Try deleting the token file and re-authenticating

### Still hitting quota limits
- Create more projects (4, 5, 6, or more)
- Each project adds 10,000 units/day
- Run `python check_rotation_status.py` to verify all are set up
