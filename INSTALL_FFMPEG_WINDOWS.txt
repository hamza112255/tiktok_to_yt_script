============================================================
 How to Install FFmpeg on Windows
============================================================

FFmpeg is required for:
- Adding watermark text to videos
- Splitting videos into 30-second shorts

============================================================
METHOD 1: Manual Installation (Recommended)
============================================================

Step 1: Download FFmpeg
-----------------------
1. Go to: https://www.gyan.dev/ffmpeg/builds/
2. Click: "ffmpeg-release-essentials.zip" (under "release builds")
3. Download will start (~70 MB)

Step 2: Extract Files
----------------------
1. Extract the ZIP file
2. You'll see a folder like: ffmpeg-6.0-essentials_build
3. Rename it to just: ffmpeg
4. Move the folder to: C:\ffmpeg
   (So you have: C:\ffmpeg\bin\ffmpeg.exe)

Step 3: Add to PATH
--------------------
1. Press Windows Key + R
2. Type: sysdm.cpl
3. Press Enter
4. Click "Advanced" tab
5. Click "Environment Variables" button
6. Under "System variables", find "Path"
7. Click "Edit"
8. Click "New"
9. Type: C:\ffmpeg\bin
10. Click OK on all windows

Step 4: Verify Installation
----------------------------
1. Open NEW Command Prompt (important: must be new)
2. Type: ffmpeg -version
3. You should see version info

If it works, you're done! ✅

============================================================
METHOD 2: Using Chocolatey (Easier)
============================================================

If you have Chocolatey package manager:

1. Open PowerShell as Administrator
2. Run: choco install ffmpeg
3. Wait for installation
4. Close and reopen Command Prompt
5. Test: ffmpeg -version

Done! ✅

============================================================
METHOD 3: Using Winget (Windows 11)
============================================================

If you have Windows 11:

1. Open Command Prompt
2. Run: winget install ffmpeg
3. Follow prompts
4. Close and reopen Command Prompt
5. Test: ffmpeg -version

Done! ✅

============================================================
TROUBLESHOOTING
============================================================

"ffmpeg is not recognized..."
→ PATH not set correctly
→ Make sure you added C:\ffmpeg\bin (not C:\ffmpeg)
→ Close and reopen Command Prompt after adding to PATH

"Access denied"
→ Run Command Prompt as Administrator
→ Or move ffmpeg folder to a location you have access to

Still not working?
→ Restart your computer
→ Try again with a fresh Command Prompt

============================================================
VERIFY IT'S WORKING
============================================================

After installation, test with your script:

1. cd "D:\tiktok to youtube"
2. python tiktok_to_youtube.py
3. Look for: "→ Adding watermark: Lahori Twins"

If you see that message, FFmpeg is working! ✅
