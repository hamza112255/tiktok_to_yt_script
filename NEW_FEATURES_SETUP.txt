============================================================
 NEW FEATURES ADDED - Setup Guide
============================================================

Three new features have been added to your TikTok to YouTube automation:

1. ✅ WATERMARK: Adds "Lahori Twins" text on videos
2. ✅ FEMALE DETECTION: Skips videos with people detected
3. ✅ VIDEO SPLITTING: Splits long videos into 30-second shorts

============================================================
INSTALLATION STEPS
============================================================

Step 1: Install FFmpeg (Required for watermark & splitting)
------------------------------------------------------------

WINDOWS:
1. Download FFmpeg from: https://www.gyan.dev/ffmpeg/builds/
2. Download "ffmpeg-release-essentials.zip"
3. Extract to: C:\ffmpeg
4. Add to PATH:
   - Right-click "This PC" → Properties → Advanced System Settings
   - Environment Variables → System Variables → Path → Edit
   - Add: C:\ffmpeg\bin
   - Click OK
5. Restart Command Prompt
6. Test: ffmpeg -version

LINUX (Oracle Cloud):
sudo apt update
sudo apt install ffmpeg -y
ffmpeg -version

Step 2: Install Python Dependencies
------------------------------------------------------------

WINDOWS:
cd "D:\tiktok to youtube"
pip install -r requirements.txt

LINUX (Oracle Cloud):
cd ~/tiktok-youtube
pip3 install -r requirements.txt

This will install:
- opencv-python (for video processing)
- ultralytics (YOLO AI model for person detection)
- numpy, pillow (image processing)

Step 3: Upload New Files to Oracle Cloud
------------------------------------------------------------

If you're using Oracle Cloud, upload these files:

From Windows PowerShell:
cd "D:\tiktok to youtube"

scp -i Downloads\oracle-ssh-key.key tiktok_to_youtube.py ubuntu@YOUR_IP:~/tiktok-youtube/
scp -i Downloads\oracle-ssh-key.key config.json ubuntu@YOUR_IP:~/tiktok-youtube/
scp -i Downloads\oracle-ssh-key.key video_processor.py ubuntu@YOUR_IP:~/tiktok-youtube/
scp -i Downloads\oracle-ssh-key.key requirements.txt ubuntu@YOUR_IP:~/tiktok-youtube/

Step 4: Restart Service (Oracle Cloud)
------------------------------------------------------------

SSH into your VM:
ssh -i oracle-ssh-key.key ubuntu@YOUR_IP

cd ~/tiktok-youtube
pip3 install -r requirements.txt

# Restart the service
sudo systemctl restart tiktok-youtube

# Check logs
sudo journalctl -u tiktok-youtube -f

============================================================
CONFIGURATION (config.json)
============================================================

New settings added to youtube_settings:

{
  "youtube_settings": {
    ...
    "add_watermark": true,              // Enable/disable watermark
    "watermark_text": "Lahori Twins",   // Text to display
    "skip_female_videos": true,         // Enable/disable person detection
    "split_long_videos": true,          // Enable/disable video splitting
    "split_duration_seconds": 30        // Duration of each split (seconds)
  }
}

============================================================
HOW IT WORKS
============================================================

1. WATERMARK:
   - Adds "Lahori Twins" text in top-left corner
   - White text with black shadow for visibility
   - Helps with copyright/branding

2. FEMALE DETECTION:
   - Uses YOLO AI model to detect people in video
   - Samples 10 frames throughout the video
   - If people detected in >30% of frames, skips video
   - Note: Basic detection, not 100% accurate for gender

3. VIDEO SPLITTING:
   - Checks video duration
   - If longer than 30 seconds, splits into parts
   - Each part is uploaded separately
   - Titles include "(Part 1/3)", "(Part 2/3)", etc.
   - Original long video is deleted after splitting

============================================================
TROUBLESHOOTING
============================================================

Error: "ffmpeg not installed"
→ Install FFmpeg (see Step 1 above)

Error: "Could not load AI model"
→ Run: pip install ultralytics
→ First run downloads YOLO model (~6MB)

Error: "opencv-python not found"
→ Run: pip install opencv-python

Person detection not working:
→ Set "skip_female_videos": false to disable
→ Or wait for first run to download YOLO model

Videos not splitting:
→ Check ffmpeg is installed: ffmpeg -version
→ Check "split_long_videos": true in config.json

Watermark not showing:
→ Check ffmpeg is installed
→ Check "add_watermark": true in config.json

============================================================
DISABLE FEATURES
============================================================

To disable any feature, edit config.json:

// Disable watermark
"add_watermark": false,

// Disable person detection
"skip_female_videos": false,

// Disable video splitting
"split_long_videos": false,

Then restart:
- Windows: Just restart the script
- Oracle Cloud: sudo systemctl restart tiktok-youtube
