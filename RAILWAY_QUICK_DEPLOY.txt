========================================
RAILWAY QUICK DEPLOY GUIDE
Instagram/Snapchat to YouTube
========================================

STEP 1: PREPARE CREDENTIALS
----------------------------
# Run locally first to generate token.json
python insta_snap_youtube.py

# Encode credentials for Railway
python encode_for_railway_insta.py

This creates:
- client_secret_b64.txt
- token_b64.txt

========================================
STEP 2: PUSH TO GITHUB
----------------------------
git add .
git commit -m "Add Instagram/Snapchat downloader"
git push origin main

========================================
STEP 3: DEPLOY TO RAILWAY
----------------------------
1. Go to https://railway.app
2. Click "New Project"
3. Select "Deploy from GitHub repo"
4. Choose your repository
5. Wait for build to complete

========================================
STEP 4: ADD ENVIRONMENT VARIABLES
----------------------------
In Railway dashboard → Variables:

REQUIRED:
---------
YOUTUBE_CLIENT_SECRET_B64=<paste from client_secret_b64.txt>
YOUTUBE_TOKEN_JSON=<paste from token_b64.txt>
AUTO_UPLOAD_TO_YOUTUBE=true

OPTIONAL:
---------
ADD_WATERMARK=true
WATERMARK_TEXT=Lahori Twins
SKIP_FEMALE_VIDEOS=false
SPLIT_LONG_VIDEOS=true
SPLIT_DURATION_SECONDS=38
VIDEO_PRIVACY=public
DEFAULT_DESCRIPTION=#rajabfamily #rajabbutt #viralshorts #maandogar #shezi #haidershah #haiderlive #jahangir

========================================
STEP 5: UPDATE PROCFILE
----------------------------
# Rename Procfile.insta to Procfile
copy Procfile.insta Procfile

# Or edit Procfile to:
web: python -u railway_runtime_setup.py && python -u insta_snap_youtube.py

# Commit and push
git add Procfile
git commit -m "Update Procfile"
git push origin main

========================================
STEP 6: VERIFY DEPLOYMENT
----------------------------
In Railway dashboard:
1. Click on your service
2. Go to "View Logs"

========================================
TROUBLESHOOTING
========================================

PROBLEM: "client_secret.json not found"
SOLUTION: Check YOUTUBE_CLIENT_SECRET_B64 variable

PROBLEM: "YouTube authentication failed"
SOLUTION: Regenerate token.json locally and re-encode

PROBLEM: "ffmpeg not installed"
SOLUTION: Add nixpacks.toml with FFmpeg

PROBLEM: "Memory limit exceeded"
SOLUTION: Set SKIP_FEMALE_VIDEOS=false

PROBLEM: "No new content found"
SOLUTION: Normal - platforms may block. Script retries.
